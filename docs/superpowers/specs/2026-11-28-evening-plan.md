## 2. 참고

- 글자 선택: 구글 문서·노션·삼성 노트는 폰의 선택(손잡이·복사 메뉴)을 그대로 쓰고, 자기 도구는 키보드 위나 화면 아래 막대에 둔다. 낱말 위 말풍선을 따로 띄우지 않는다.
- 누가 언제: 구글 문서는 '수정 기록', 노션은 블록 옆 정보. 우리는 고르면 바로 아래에 한 줄(따로 화면 없이).
- 숨은 사진: 카톡·아이메시지는 사진을 누르면 크게. 숨은 것(보이지 않는 잉크)은 문지르거나 누르면 드러난다. 누르면 바로가 가장 쉽다.
- 글자 효과: 아이메시지의 말풍선·화면 효과(쾅, 크게, 부드럽게, 보이지 않는 잉크), 카톡의 이모티콘 움직임.
- 녹음: 크롬 안드로이드는 `capture`가 있는 소리 입력에서 녹음 요청(RECORD_SOUND)을 받는 앱이 없으면 일반 파일 창을 연다(삼성 녹음은 받지 않는 폰이 많다).
- 보내기: 카톡은 링크를 미리보기 카드로, 그림·동영상 파일도 받는다. 인스타는 공유 시트로 그림·동영상만(스토리·게시물·메시지), 링크 글은 안 받는다.

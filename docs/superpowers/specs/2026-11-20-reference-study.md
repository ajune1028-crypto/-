# 잘 만든 앱들에서 배울 것: 편의 기능, 쓰임, 아이콘, 우리 앱에 넣는 법 (11월 20일)

사용자의 말(11월 20일):

> "그 거의 모든 것들을 다른 공개된 코딩 그쪽을 보고서 하라고… 다 있는 거 찾아서 해 보려는 걸 먼저 해 봐"
>
> "진짜 프로처럼, 그리고 또 몰입력은 진짜 좋게. 이 앱의 본질을 생각하기도 하고"
>
> "그 본질적인 그 앱들의 편의성이라던지, 그 기능들이 어디에 쓰이고 어떤 아이콘을 취했으며, 어떻게 넣으면 좋을 것 같고, 그런 거 먼저 해. 그리고 항상 본질 생각하고 어떻게 넣을지. 그림 모드에서는 이렇게 하는 게 나을 것 같고, 그런 거"

이 문서는 사람들이 오래 써서 검증된 앱(프로크리에이트, 플립어클립, 굿노트, Excalidraw, Klecks, 개러지밴드, 스크리블·갈틱폰 등)의 편의 기능을 하나씩 본다. 각 기능마다 다음을 적는다.

- 무엇을 위해 쓰이나
- 그 앱은 어떤 아이콘이나 몸짓으로 했나
- 우리 앱의 어느 방에 어떻게 넣나
- 본질에 맞나

코드를 옮길 수 있는 공개 코드(MIT·Apache·BSD·ISC)는 함께 적었다. 만들기 전에 이 문서로 먼저 재고, 만들고 나면 '상태'를 바꾼다.

## 0. 결론 먼저

**배울 것의 핵심은 기능의 개수가 아니다. 손이 하던 대로 바로 되는 것(몸짓), 그리고 친구가 바로 옆에 있는 느낌(실시간)이다.**

1. **친구가 긋는 중인 선이 바로 보여야 한다.** 지금은 손을 뗀 뒤에야 보인다(Excalidraw·Figma는 긋는 중에 보인다). '같이'의 바탕이라 가장 먼저 한다. 같은 통로로 **레이저 포인터**(굿노트·Excalidraw: 가리키면 빛이 남았다가 사라짐)와 **친구 펜 위치**도 보낸다.
2. **그림의 기본 몸짓은 프로크리에이트를 따른다.**
   - 두 손가락으로 톡 치면 되돌리기, 세 손가락으로 톡 치면 다시하기.
   - 가만히 꾹 누르면 스포이트, 긋다가 멈추면 모양 잡기(이미 있음).
   - 색 동그라미를 끌어다 놓으면 채우기.
   - 손떨림 보정.

   버튼을 찾지 않아도 된다. 아이패드에서 그리는 사람이면 이미 손에 익은 것들이다(하던 대로).
3. **애니메이션 방은 플립어클립의 쉬움에 프로크리에이트 애니메이션의 정확함을 더한다.**
   - 아래에 장 띠, 양파 껍질, 재생·반복·빠르기, 한 장 길게 보여주기, 복제해서 고치기.
   - 우리만의 것: 친구와 장을 나눠 그리기, 노래 방에서 흥얼거린 노래를 배경음으로 붙이기.
4. **미니게임은 디스코드 활동이나 아이메시지 게임처럼 '초대 한 번'으로 시작한다.**
   - 흐름: 수락 → 화면이 살짝 어두워지며 3·2·1 → 게임.
   - 판은 짧다. 결과는 방에 한 줄로 남는다(쌓인다).
   - 그려서 맞히기는 **초성 힌트**로 한국어답게 한다.
5. **노래에는 개러지밴드의 카운트인(녹음 전 '하나 둘 셋 넷')과 조 맞추기를 넣는다.** 흥얼거림 인식은 Spotify basic-pitch(Apache)의 모델로 높인다.
6. **'쌓인다'를 눈으로 보여 주는 타임랩스를 넣는다.** 프로크리에이트는 혼자 그린 과정을 보여 준다. 우리는 **같이 그린 과정**을 사람 색 그대로 다시 본다. 모든 획에 시간과 사람이 이미 들어 있어서 우리만 쉽게 할 수 있다.

## 1. 잴 때 쓰는 것

본질 다섯(본질 문서 3절):

1. 같이가 기본
2. 하던 대로
3. 쌓인다
4. 흐른다
5. 가리지 않는다

질문 다섯(4절):

1. 친구 화면에서도 바로 같은 일이 일어나나?
2. 처음 보는 친구가 설명 없이 할 수 있나?
3. 내일 그대로 있고 이어서 할 수 있나?
4. 다른 방으로 가져갈 수 있나?
5. 내용을 얼마나 덮나? 못 누르는 게 보이나?

아래 표의 '본질'은 이 다섯 중 어디에 닿는지다. 어긋나는 것은 넣지 않거나 바꿔서 넣는다.

### 2.4 같이 (우리 앱의 바탕)

| 따라가기 | 친구가 보여 주는 곳을 같이 본다 | Excalidraw: 친구 동그라미(아바타)를 누르면 그 사람 화면을 따라감 | 위 막대의 친구 색 점을 누르면 '따라가기'(그림 방·화이트보드): 친구가 확대·이동하는 대로 내 화면도 | 같이 | 3 |
| 타임랩스 | 그림이 만들어진 과정을 다시 본다 | 프로크리에이트: 동작(스패너) → 비디오 → 타임랩스 다시보기 | 그림 방·화이트보드 메뉴에 '그린 과정 보기'. 모든 획을 그은 순서대로, 사람 색과 이름이 잠깐 붙어 다시 그려진다. 빠르기 조절, 영상 저장 | 쌓인다, 같이 | 3 |

**그림 방은 이렇게 하는 게 낫다(판단).**
- 도구는 아래에 한 덩어리로 둔다. 프로크리에이트처럼 화면 네 귀퉁이로 흩지 않는다(우리 다른 방과 같은 자리).
- 몸짓을 1순위로 둔다. 두 손가락 톡, 꾹 스포이트, 색 끌어 놓기를 쓰면 버튼을 거의 누르지 않는다.
- 레이어 창과 색 원판은 필요할 때만 뜨는 작은 창이다. 바깥을 누르면 닫히고 그 누름으로는 그려지지 않는다(이미 그렇게 함).
- 처음 들어온 친구에게는 몸짓 세 가지를 한 번만 작게 알려 준다. 이 기기에서 한 번 보면 다시 안 뜬다.

**애니메이션 방은 이렇게 하는 게 낫다(판단).**
- 그림 방 하나를 장 여러 개로 늘린 것이다. 붓·레이어·몸짓·실시간이 모두 같다(처음부터 다시 만들지 않는다).
- 화면에는 '종이와 아래 띠'만 둔다.
- 처음 쓰는 사람을 위한 첫 화면은 빈 장 두 개와 양파 껍질이 켜진 상태다. 무엇을 할지 바로 보인다.

## 4. 미니게임 (방 안에서 잠깐)

본 앱과 코드:

- 카훗: 3·2·1
- 스크리블·캐치마인드: 그려서 맞히기. scribble.rs(BSD), Skribblrs.io(MIT)의 판 흐름을 읽음
- 갈틱폰

## 8. 하는 순서 (본질 순, 3분의 1마다 시험판)

1. 실시간 선 + 친구 펜 위치 + 레이저 포인터: 그림 방·화이트보드·텍스트 방의 '같이'
2. 그림 방 몸짓과 붓
   - 두 손가락 톡 되돌리기, 세 손가락 톡 다시하기
   - 꾹 스포이트
   - 손떨림 보정
   - 스케치·크레용 붓
   - ⋮ 바 튕기기

   → **시험판 (1/3)**
3. 애니메이션 방: 장 띠, 양파 껍질, 재생, 길게, 복제, 장 나눠 그리기
4. 미니게임: 초대, 3·2·1, 가위바위보, 오목, 결과 한 줄, 홈에서 끄기

   → **시험판 (2/3)**
5. 노래: 카운트인, 조 맞추기, 화음 붙이기
6. 채우기(색 끌어 놓기), 색 원판, 그림 방 크기 막대, 타임랩스, 그려서 맞히기(초성 힌트)

   → **시험판 (3/3)**
7. 그다음: 소리 붙이기, 움직임 녹화, 영상·GIF, basic-pitch, 반응·손 흔들기, 따라가기, 문지르기

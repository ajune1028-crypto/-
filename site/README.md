# site/

`index.html` is the tested one-file build of the app (`node tools/bundle.mjs`, then every screen scenario with `node tools/e2e.mjs --dist`).
It is kept here so any browser can open the app over https straight from this public repository, without Claude and before GitHub Pages is turned on:

https://raw.githack.com/ajune1028-crypto/-/main/site/index.html

(The lasting address is GitHub Pages: https://ajune1028-crypto.github.io/-/ once the owner sets Settings → Pages → Source to "GitHub Actions".)

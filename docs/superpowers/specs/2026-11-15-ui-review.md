# UI 검토 (애플·삼성 기준으로 깐깐하게) — 2026-11-15

사용자: "애플과 삼성의 아주 깐깐한 UI 개발 디자인하는 전문가처럼… 의견 제시 및 수락 물어보고. 본질과 목적… 빠진 거 없나 체크도". 아래는 제안이고, 사용자가 고른 것만 만든다(고른 결과는 rulings에 적는다).

## 0. 무엇을 위한 화면인가

친구와 링크 하나로 같은 자리에서 쓰고·부르고·놓은 것이 같이 만든 것이 된다(본질 문서). 그래서 화면의 일은 둘뿐이다: **만드는 동안 방해하지 않기**(가리지 않는다·흐른다), **만든 것을 같이 보고 이어 가기 쉽게**(같이·쌓인다). 아래 기준은 모두 이 둘로 잰다.

## 1. 이번에 이미 고친 것 (사용자가 사진으로 짚은 것)

- 펜으로 그릴 때 글자 선택(파란 손잡이, 복사하기·찾아보기)이 뜨던 것: 입력 칸 말고는 어디도 선택되지 않는다. 선은 프레임마다 한 번, 이미 그린 것은 그림으로 두고 그 위에만 그린다(끊김 없음).
- 아이패드 양옆 검은 여백: 앱이 화면을 꽉 채운다. 글 종이도 옆으로 넓어진다.
- 화이트보드 막대 둘레의 색 번짐, 다크의 무거운 검정 그림자: 보드에서는 번짐 없이, 다른 곳은 내 글라스 색으로 옅게.
- 배경 위 글자·아이콘: 뒤의 밝기를 실제로 재서 흰색/검정/더 진한 검정.
- 시트: 닫기 버튼 한 번, 위에서 아래로 당기면 닫힘(내용이 내려가 있으면 먼저 올라감), 미끄러지는 움직임.
- 화이트보드: 1/20까지 축소, 확대·축소는 아무것도 서로 어긋나게 하지 않음, 늘이기는 그 카드만.
- 투명 글라스.

## 2. 제안 (고르면 만든다)

### 화이트보드 도구
- **모드 막대 옮기기**: 막대를 꾹 눌러 들어 위·아래·왼쪽·오른쪽 끝에 놓으면 붙는다(왼·오른쪽이면 세로로). 오른쪽 도구는 막대 반대편으로 자동. — 추천.
- **막대 꾸미기**: 순서 바꾸기, 안 쓰는 모드 숨기기, 크기(작게·보통·크게), 글자 없이 아이콘만. 이 기기에만 저장.
- **그릴 때 막대가 옅어지기**: 펜이 닿아 있는 동안 막대·도구가 15%로 옅어져 그림만 보인다(몰입).

### 노래 ↔ 화이트보드 흐름
- **순서 목록**: 저장한 순서(1~5)에 이름을 붙이고, 목록에서 듣고, 복제하고, 노래 방으로 보내기(순서대로 한 줄에 이어 붙임). — 추천.
- **화이트보드 → 노래 방 보내기**: 고른 카드나 올가미 안을 순서대로.
- **홈에서 꾹 → 보내기**: 무엇을(전체·순서·글) 어디로.
- **노래 방 올가미**: 클립을 둘러 묶어 옮기기·복사·음소거·색·빠르기·지우기·재생·반복.

### 움직임과 느낌
- **움직임 하나로 통일**: 시트·메뉴·카드·막대가 같은 곡선(아이폰 시트 곡선)과 0.2~0.4초. 움직임 줄이기 설정을 따른다. — 추천.
- **색이 섞일 때 '띠리링'과 소용돌이**: 일상 텍스트 방에서 두 번 눌러 색이 섞일 때 짧은 맑은 소리와 색이 도는 움직임. 설정에서 끄기.
- **끌 때·붙을 때 짧은 진동**(안드로이드).

### 보기와 배치
- **홈 미리보기**: 방 줄에 최근 것 한 줄(글 첫 줄, 노래 음 막대, 보드 작은 그림). — 추천.
- **노래 방 줄 머리**: 줄마다 누구 색·음소거·혼자 듣기(개러지밴드처럼).
- **아이패드 가로 옆 패널**: 클립 정보·레퍼런스를 옆에 고정.
- **글자·아이콘 체계 정리**: 제목·본문·설명 3단, 아이콘 굵기 하나, 모서리 둥글기 3단.

## 3. 빠진 것 점검 (원문 대비)

- 첫 설명의 "노래 잇기 모드"(다른 창에서 한 줄로 늘어놓고 순서 바꾸기, 쌓기는 직선, 순서 저장 1·2·3…): 순서 칸은 있으나 **잇기 창은 아직 없음** → '순서 목록' 제안과 함께 만드는 것이 맞다.
- 글쓰기 방(A4·스크롤 선택), 사진 방(셀로그), 통합 방: 아직 없음(홈에 준비 중).
- 실시간 같이: 공개 주소에서는 서버(Firebase) 주소가 들어가야 된다.
- 색 섞기의 효과음: 원문 파일에는 없고 사용자가 이번에 말함 → 위 제안에 넣음.
